# Product Scope

## In Scope

- User authentication and workspace administration.
- Personal and team workspace management.
- REST API request building and response inspection.
- Collection and folder organization.
- Environment and variable resolution.
- Request history and version tracking.
- Synthetic payload generation from schema and examples.
- Rule-based test case generation and basic execution.
- Request timeline and basic performance dashboarding.
- Smart documentation generation and publication states.
- Sequential request flow orchestration.
- Import and export of common API formats.

## Out of Scope for MVP

- Real-time collaboration.
- Full auto-generated enterprise security testing coverage.
- Large-scale distributed load generation from browser clients.
- Browser extension and desktop-native clients in the first release.
- gRPC, SSE, and WebSocket support beyond the roadmap.

## Release Scope Summary

- MVP: core workspace, request builder, collections, environment, history, payload generation, rule-based tests, simple timeline, documentation, sequential flow.
- Version 1: team permissions, AI-assisted features, test suites, performance dashboard, import/export expansion, sharing.
- Version 2: collaboration, advanced flows, scheduled tests, public docs portal, extended protocols.
- Future: desktop/extension agents, enterprise governance, plugin ecosystem, self-hosted AI.
