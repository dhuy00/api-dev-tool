# Collections and Request Organization

## Overview

Collections provide a structured way to organize requests, folders, and examples.

## Core Features

- Create and nest folders.
- Save requests into collections.
- Move and duplicate requests.
- Rename, sort, tag, and favorite requests.
- Search and recent request access.
- Bulk actions and import/export.

## Supported Import and Export Sources

- OpenAPI
- Postman Collection
- Hoppscotch Collection
- cURL
- HAR
- Native API Forge format

## MVP Positioning

Collections and folders are mandatory for the MVP, while advanced import mapping and large-format compatibility are staged by source.
