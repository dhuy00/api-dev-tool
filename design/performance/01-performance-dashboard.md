# Màn hình Performance Dashboard

## 1. Tổng quan

- **Mã màn hình:** PERF-001
- **Tên màn hình:** Performance Dashboard
- **Loại:** Dashboard Screen
- **Vị trí:** Project → Performance tab
- **Yêu cầu:** Editor role trở lên

---

## 2. Mục đích

Cấu hình và chạy performance tests, xem kết quả performance với metrics và so sánh giữa các runs.

## 4. Các thành phần UI

### 4.1 Summary Cards
- **Total Requests:** Total count
- **Success Rate:** Percentage
- **P95 Latency:** 95th percentile
- **Avg Response Time:** Average in ms

### 4.2 Charts
- **Response Time Chart:** Line chart over time
- **Requests/sec Chart:** Throughput over time
- **Status Distribution:** Pie/bar chart

### 4.3 Stats Grid
- **Min/Max/Avg:** Response times
- **P50/P90/P95/P99:** Percentiles

### 4.4 Run History Table
- Run number, timestamp, request count, success rate, avg time, P99

## 6. Run Configuration

| Parameter | Description | Limits |
|-----------|-------------|--------|
| Virtual Users (VUs) | Concurrent users | 1-100 |
| Duration | Test duration | 10-600 seconds |
| Ramp-up | Time to reach full VUs | 0-60 seconds |
| Delay | Delay between requests | 0-1000ms |
| Timeout | Per-request timeout | 5-60 seconds |

---

## 7. Safety Constraints

- Max 100 concurrent users
- Max 10-minute duration
- Rate limiting per target
- Target isolation enforced
- Auto-cancel on threshold breach (optional)
