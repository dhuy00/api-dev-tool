# Request Builder

## Overview

The request builder is the core interactive authoring and execution surface for API testing.

## Supported Methods

- GET
- POST
- PUT
- PATCH
- DELETE
- HEAD
- OPTIONS

## Request Configuration

- URL
- Query parameters
- Path parameters
- Headers
- Cookies
- Request body
- Authentication
- Timeout
- Redirect behavior
- SSL verification
- Proxy configuration for future release

## Body Modes

- None
- JSON
- XML
- Plain text
- Form URL encoded
- Multipart form-data
- File upload
- GraphQL query

## Response Viewer

- Status code and message
- Response time
- Response size
- Response headers and cookies
- Pretty/raw/preview views
- Search and copy actions
- Save as example

## Supported Protocols

### MVP

- REST/HTTP

### Roadmap

- GraphQL
- WebSocket
- Server-Sent Events
- gRPC

## MVP Positioning

The MVP must prioritize REST/HTTP request authoring, execution, and response inspection with safe defaults and extensible protocol support later.
