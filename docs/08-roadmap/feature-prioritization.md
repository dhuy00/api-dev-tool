# Feature Prioritization

## MoSCoW Summary

### Must Have

- Authentication.
- Personal workspace.
- REST request builder.
- Collections and folders.
- Environments and variables.
- Request history.
- Basic payload generation.
- Request timeline.
- Basic documentation.
- Sequential flow builder.
- cURL and OpenAPI import.

### Should Have

- Team workspace support.
- Rule-based and AI-assisted test generation.
- Basic test execution.
- Performance dashboard.
- OpenAPI/Postman import-export.

### Could Have

- Advanced documentation publishing.
- Conditional flow logic.
- Variable extraction and loop support.
- Parallel flow execution.

### Won’t Have for Now

- Real-time collaboration.
- Public documentation portal.
- Browser extension.
- Desktop agent.
- WebSocket, GraphQL, SSE, and gRPC in the first release.
