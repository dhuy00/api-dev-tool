# Màn hình Account Settings

## 1. Tổng quan

- **Mã màn hình:** SET-001
- **Tên màn hình:** Account Settings
- **Loại:** Settings Screen
- **Vị trí:** User menu → Settings → Account
- **Yêu cầu:** Must be logged in

---

## 2. Mục đích

Quản lý thông tin tài khoản cá nhân, profile, security settings, và preferences.

## 9. Acceptance Criteria

- [ ] Hiển thị profile info
- [ ] Có thể upload avatar
- [ ] Có thể edit profile fields
- [ ] Email verification status hiển thị
- [ ] Linked accounts hiển thị
- [ ] Có thể change password
- [ ] 2FA settings hoạt động
- [ ] Active sessions hiển thị
- [ ] Có thể sign out sessions
- [ ] Theme preference hoạt động
- [ ] Notification preferences hoạt động
- [ ] Sidebar navigation hoạt động
