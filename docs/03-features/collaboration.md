# Collaboration

## Overview

The collaboration module supports shared access to API artifacts and activity awareness.

## Collaboration Features

- Share collections, requests, test suites, and request flows.
- Comment and mention users.
- Activity log and change history.
- Notifications for key events.
- Conflict resolution on shared edits.

## Notification Types

- Workspace invitation.
- Mention.
- Comment reply.
- Failed scheduled test.
- Performance regression.
- Documentation updated.
- Project access changed.

## MVP Positioning

Collaboration should be scoped to sharing and activity visibility in the MVP, while real-time collaboration and presence are deferred.
