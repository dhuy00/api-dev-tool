# Search

## Overview

Search is a cross-asset discovery feature used to locate requests, documentation, environments, test cases, flows, and activity artifacts.

## Search Requirements

- Full-text search.
- Search filtering.
- Search sorting.
- Recent search history.
- Search scope control.
- Keyboard navigation.
- Highlight matched text.

## Search Scope

- Workspace
- Project
- Collection
- Folder
- Request
- Endpoint
- Documentation
- Test case
- Request flow
- Environment variable
- Execution history

## MVP Positioning

The MVP should support workspace-level and project-level search with quick filtering and result highlighting.
