# Project Management

## Overview

A project is the primary container for requests, collections, environments, flows, tests, and documentation.

## Included Assets

- Project metadata and description.
- Collections and folders.
- Requests and examples.
- Environments and variables.
- Test suites.
- Request flows.
- Performance reports.
- Documentation versions.
- Activity history.

## Project Lifecycle

- Create.
- Edit.
- Duplicate.
- Archive.
- Restore.
- Delete.
- Share.
- Export.
- Import.

## MVP Positioning

The MVP should support a project as a stable domain object with basic ownership and permission controls.
