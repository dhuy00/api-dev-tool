# MVP Scope

## MVP Objective

The MVP should prove the platform’s core differentiators with a clean, portfolio-friendly footprint.

## MVP In-Scope Features

- Authentication.
- Personal workspace.
- REST API request builder.
- Collections and folders.
- Environments and variables.
- Request history.
- JSON response viewer.
- Basic payload data generator.
- Rule-based test case generation.
- Basic test execution.
- Basic request timeline.
- Basic smart documentation.
- Sequential request flow.
- Import cURL and OpenAPI.
- Export native format.

## MVP Exclusions

- Real-time collaboration.
- Full AI autonomy.
- Full advanced performance and load testing.
- Browser extension and desktop-native support.
- Multi-protocol advanced execution in the first release.
