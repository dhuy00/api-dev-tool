# Dependencies

## Internal Dependencies

- User account and session service.
- Workspace metadata service.
- Request execution service.
- Request history and snapshot store.
- Environment and variable resolvers.
- Import and export pipeline.
- Documentation generation service.
- Flow orchestration engine.
- Performance worker and metrics store.

## External Dependencies

- OAuth providers: Google, GitHub.
- Email delivery service.
- AI service provider for optional data and test assistance.
- Object storage for snapshots, exports, and documentation assets.
- Queue/worker infrastructure for performance and import jobs.

## Platform Dependencies

- Secure secret storage.
- Metrics and tracing observability stack.
- Audit log store.
- Identity and access management integration.
